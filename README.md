# SF Pro & SF Mono Nerd Font

Apple's San Francisco fonts with Nerd Font icons for developers.

## What's Included

- **SF Pro** (Original) - Apple's system font
- **SF Mono** (Original) - Apple's monospaced font
- **SF Pro Nerd Font** - SF Pro patched with Nerd Font v0.3.4
- **SF Mono Nerd Font** - SF Mono patched with Nerd Font v0.3.4

## Features

- Complete Apple San Francisco font family
- 3,600+ developer icons and glyphs
- Perfect for terminals and code editors
- Retains original Apple font quality
